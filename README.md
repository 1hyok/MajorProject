# Kotlin Android 전공 프로젝트

전공 프로젝트의 Android 앱, Python 시각화 실험, 보고서를 모아 둔 저장소입니다.

## 구성

- `app/`: Android 앱 모듈
- `python/`: Matplotlib, NetworkX, Plotly 실험 파일
- `Reports/`: 프로젝트 보고서

## 실행

Android Studio에서 저장소 루트를 열고 Gradle 동기화가 끝나면 `app` 모듈을 실행하세요. 터미널에서 빌드하려면 저장소에 포함된 Gradle Wrapper를 사용합니다.

```sh
./gradlew :app:assembleDebug
```

## 상태

전공 프로젝트 기록입니다. 앱의 현재 배포 상태는 이 저장소에서 확인되지 않습니다.
